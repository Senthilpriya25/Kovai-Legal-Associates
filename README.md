# Kovai Legal Associates Website

GitHub Pages-ready informational website.

## Publish
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.

## Replace later
Phone, email, full office address, office hours, About text, practice areas, and client-assistance workflow.

The current form is a front-end demo only and does not transmit or store data.
